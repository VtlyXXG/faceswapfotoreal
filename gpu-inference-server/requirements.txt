#
#     pip install --no-cache-dir facexlib==0.3.0
#     pip install --no-cache-dir --force-reinstall opencv-python-headless==4.10.0.84
#
# Без facexlib восстановление лица просто выключается, сервер работает, причина
# видна на /health/ready. Полный порядок — в setup_server.sh, шаг 9.
