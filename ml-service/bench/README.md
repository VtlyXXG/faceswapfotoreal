# A/B-стенд постобработки лица

Гоняет пары **(лицо-донор, обложка)** через реальный пайплайн face-swap +
стилизатор при нескольких значениях силы, считает узнаваемость и
рассогласование фактуры и собирает HTML для сравнения глазами.

Нужен, чтобы параметры постобработки (и потом — диффузии) подбирались по
числам и по картинке на наборе обложек, а не на глаз по одному кадру.

## Подготовка входа

Разложите изображения в `bench/samples/` одним из способов:

**Один донор, много обложек** (основной сценарий книги):

```
bench/samples/
  source.jpg          лицо ребёнка
  target_castle.png   обложки
  target_space.png
  target_forest.png
```

**Папка на пару** (разнородные кейсы):

```
bench/samples/
  case_castle/  source.jpg  target.png
  case_space/   source.jpg  target1.png  target2.png
```

Донор — `source.<ext>`, обложки — `target*.<ext>`
(`.jpg`, `.jpeg`, `.png`, `.webp`).

## Запуск

```powershell
cd ml-service
.\.venv\Scripts\python.exe -m bench
.\.venv\Scripts\python.exe -m bench --strengths 0.6,1.0,1.4
.\.venv\Scripts\python.exe -m bench --input bench/samples --out bench/out
```

Результат:

- `bench/out/report.html` — сводка, рекомендация и кропы лиц по вариантам
  бок о бок. Самодостаточный файл (изображения встроены), открывается локально.
  **Не публикуется** — на кропах персональные фото.
- `bench/out/results.json` — метрики для дальнейшего анализа.

## Как читать

- **Узнаваемость** — косинус ArcFace-эмбеддингов донора и результата. Порог
  0.55; ниже подсвечено красным. Считается повторной детекцией на результате.
- **Рассогласование фактуры** — расхождение лица и окружения (энергия высоких
  частот + моменты LAB). Меньше — лучше; 0 значит, что лицо статистически
  неотличимо от иллюстрации вокруг.
- **Рекомендация** — вариант с минимальным рассогласованием среди тех, что
  держат узнаваемость и согласуют фактуру не хуже, чем без обработки. Именно
  минимум, а не максимальная сила: у классического стилизатора фактура
  немонотонна по strength — на больших значениях донорское зерно перебирается.

## Замечания

- Стилизатор в стенде всегда `classical`, независимо от `ML_STYLE_PROVIDER`:
  стенд мерит алгоритм, а не текущий конфиг сервиса.
- Swap считается один раз на пару и переиспользуется всеми вариантами — это
  самая дорогая операция (~13 c на 4K на CPU). Вариантов добавлять дёшево.
- Пара без распознанного лица пропускается с предупреждением, стенд не падает.
- `bench/samples/` и `bench/out/` в `.gitignore`: входные фото и отчёты
  с лицами в репозиторий не попадают.
