# Учёт заказов

Обновлять по каждому событию (не пачками): отклик отправлен → ответ получен
→ заказ получен → в работе → сдан → оплачен. Формат площадки не важен —
Kwork, FL.ru, Habr, Upwork, Fiverr, Telegram — все заказы в одну таблицу.
